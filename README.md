
# 🧪 Manual Testing Project – The Dummy Site

## 📌 Project Overview

This project demonstrates manual testing of a web application (The Dummy Site). The goal was to evaluate system behavior under valid, invalid, and edge-case inputs.

## 🎯 Objectives

* Verify input validation
* Identify functional bugs
* Detect security issues (e.g., OTP bypass)
* Simulate real user behavior

## 🧪 Modules Tested

* Signup / Login
* Profile Update
* Shipping Form
* Checkout Process
* Feedback Form
* Multi-Step Form
* 2FA Authentication

## 🧠 Testing Techniques Used

* Functional Testing
* Negative Testing
* Exploratory Testing
* Validation Testing

## 🐞 Key Bugs Identified

* Invalid email formats accepted
* Special characters allowed in name fields
* No validation in shipping & checkout forms
* 2FA authentication bypass (Critical)

## 📊 Files Included

* TestCases.xlsx → Structured test cases
* BugReport.docx → Detailed bug reports
* Screenshots → Evidence of bugs

## 📚 Key Learnings

* Importance of input validation
* Real-world testing scenarios
* Security vulnerabilities in authentication
